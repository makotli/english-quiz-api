# English Vocabulary Quiz API

Node.js and Express backend for English learning quizzes. It supports the original static vocabulary dataset and newer endpoints that use external sources.

## Features

- Static word association quizzes grouped by category.
- Difficulty levels from `1` to `5`.
- Random category and shuffled options for `/quiz`.
- Answer scoring with feedback and explanations.
- Dictionary lookup through [Dictionary API](https://api.dictionaryapi.dev/).
- Dynamic quiz generation from live dictionary definitions.
- Short reading text from an external source when available, with generated fallback clearly labeled.

## Categories

- `food`
- `travel`
- `hotel`
- `daily-life`
- `business`
- `emotions`

## Difficulty

- `1`: basic words, A1
- `2` to `3`: intermediate, A2-B1
- `4` to `5`: advanced, B2-C1

## Setup

```bash
npm install
npm start
```

The API runs on `http://localhost:3000` by default. Set `PORT` to use another port.

## Endpoints

### GET `/quiz`

Generates a quiz from the predefined vocabulary dataset.

Query params:

- `level`: required, integer from `1` to `5`
- `category`: optional category slug

Example:

```bash
curl "http://localhost:3000/quiz?level=2&category=food"
```

Response:

```json
{
  "words": ["bar", "drink", "alcohol"],
  "options": ["beer", "cat"],
  "correct": "beer",
  "explanation": "Beer is an alcoholic drink commonly served in a bar.",
  "category": "food",
  "level": 2,
  "cefr": "A2-B1"
}
```

### GET `/word`

Looks up a word using Dictionary API.

Query params:

- `word`: required English word

Example:

```bash
curl "http://localhost:3000/word?word=bright"
```

Response shape:

```json
{
  "word": "bright",
  "phonetic": "/brait/",
  "meanings": [
    {
      "partOfSpeech": "adjective",
      "definitions": ["Giving off a great deal of light."],
      "synonyms": ["shining", "luminous"]
    }
  ],
  "examples": ["The room was bright and clean."],
  "synonyms": ["shining", "luminous"],
  "source": {
    "type": "external",
    "name": "Dictionary API",
    "url": "https://api.dictionaryapi.dev/api/v2/entries/en/bright"
  }
}
```

### GET `/quiz-from-word`

Uses Dictionary API data to create a definition-based quiz for a specific word.

Query params:

- `word`: required English word
- `level`: required, integer from `1` to `5`

Example:

```bash
curl "http://localhost:3000/quiz-from-word?word=bright&level=2"
```

Response shape:

```json
{
  "question": "Which word best matches this definition?",
  "word": "bright",
  "definition": "Giving off a great deal of light.",
  "partOfSpeech": "adjective",
  "words": ["giving", "light", "great"],
  "options": ["bright", "invoice"],
  "correct": "bright",
  "explanation": "'bright' means: Giving off a great deal of light.",
  "level": 2,
  "source": {
    "type": "external",
    "name": "Dictionary API",
    "url": "https://api.dictionaryapi.dev/api/v2/entries/en/bright"
  }
}
```

### GET `/reading`

Creates a short reading text from a topic and labels the source. The API first tries to use Wikipedia REST API as an external source. If no usable source is found, it returns a locally generated passage and marks it as generated.

Query params:

- `topic`: required topic
- `level`: required, integer from `1` to `5`

Example:

```bash
curl "http://localhost:3000/reading?topic=coffee&level=3"
```

External-source response shape:

```json
{
  "topic": "coffee",
  "title": "Coffee",
  "level": 3,
  "text": "Coffee is a beverage prepared from roasted coffee beans...",
  "source": {
    "type": "external",
    "name": "Wikipedia REST API",
    "url": "https://en.wikipedia.org/wiki/Coffee",
    "note": "This reading is based on an external source and shortened by the API."
  }
}
```

Generated fallback response shape:

```json
{
  "topic": "custom topic",
  "title": "custom topic",
  "level": 2,
  "text": "custom topic is useful for English practice...",
  "source": {
    "type": "generated",
    "name": "Local reading generator",
    "url": null,
    "note": "No external source was available, so this reading was generated by the API."
  }
}
```

### POST `/answer`

Scores an answer.

Body:

```json
{
  "answer": "beer",
  "correct": "beer"
}
```

Example:

```bash
curl -X POST "http://localhost:3000/answer" \
  -H "Content-Type: application/json" \
  -d "{\"answer\":\"beer\",\"correct\":\"beer\"}"
```

Response:

```json
{
  "isCorrect": true,
  "feedback": "Correct! 'beer' is related to bar, alcohol, drink.",
  "explanation": "Beer is an alcoholic drink commonly served in a bar."
}
```
